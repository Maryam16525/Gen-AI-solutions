Gen-AI Solutions

Gen-AI Solutions is a repository dedicated to building and deploying Generative AI applications using Azure services, OpenAI models, and advanced search techniques. This project includes implementations of hybrid search, Retrieval-Augmented Generation (RAG), and intelligent virtual assistants to enhance AI-driven automation and self-service capabilities.

Features

Hybrid Search: Combines keyword-based and vector search for improved retrieval.

Retrieval-Augmented Generation (RAG): Enhances LLM responses with relevant contextual data.

Azure OpenAI & Kusto Integration: Connects with Azure AI services and Kusto for real-time data processing.

Streamlit-based UI: Provides an interactive and user-friendly interface.

Self-Service AI Assistants: Enables teams to build AI-powered solutions with minimal coding.

Installation

Prerequisites

Python 3.8+

Git

Azure account with OpenAI and Kusto access

Setup

Clone the repository:

git clone https://github.com/Maryam16525/Gen-AI-solutions.git
cd Gen-AI-solutions

Create a virtual environment and activate it:

python -m venv venv
source venv/bin/activate  # On macOS/Linux
venv\Scripts\activate     # On Windows

Install dependencies:

pip install -r requirements.txt

Usage

Set up your environment variables for Azure services.

Run the Streamlit app:

streamlit run app.py

Access the application via the provided local URL.
